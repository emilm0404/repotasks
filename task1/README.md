# Task 1

Console app with four helper methods stored in `task1.cs`.

## Methods
- `IsPowerOfTwo(long value)` → returns true when `value` is a power of two.
- `Reverse(string text)` → reverses the input string.
- `Replicate(string text, int count)` → repeats the string `count` times.
- `PrintOddNumbers()` → prints odd numbers from 1 to 99.

## Run
```bash
cd task1
dotnet run
```
